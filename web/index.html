api para desarrolladores

La API es asincrona y funciona con API key. Creas una generacion, recibes un id y consultas su estado hasta que termina. Las claves las entrega quien administra el servicio. 


        

        

          
GET /v1/models
modelos, formatos y estilos disponibles

          
POST /v1/generations
crea una generacion: model, prompt, n, aspect, images, style, negative, nsfw

          
GET /v1/generations/:id
estado e imagenes de la generacion

          
POST /v1/images/generations
compatible con el formato de OpenAI, responde al terminar
